# RANDOM PASSPORT — OFF THE MAP

한국인에게 익숙한 관광 도시를 제외하고, 덜 알려진 세계의 도시로 떠나는 인터랙티브 랜덤 여행 웹사이트.
3D 지구본 → 랜덤 추첨 → 곡선 항적 비행 → 도시 정보 → 디지털 여권 도장 → 여행 통계까지 하나의 데이터 흐름으로 연결됩니다.

## 실행 방법

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # dist/ 에 정적 파일 생성 (base: './' — 하위 폴더 배포 가능)
npm run preview    # 빌드 결과 확인
```

Node 20 이상 권장. 해시 라우팅(`#/stats` 등)을 사용하므로 서버 리라이트 설정 없이 어떤 정적 호스팅에서도 동작합니다.

## 화면 / 라우트

| 라우트 | 화면 |
|---|---|
| `#/` | EXPLORE — 3D 지구본 메인, 랜덤 추첨, 비행 애니메이션, 도착 패널 |
| `#/destination/:id` | DISCOVER — 목적지 정보 (히어로, 관광지, 음식, 언어·통화·문화, 여행 팁) |
| `#/passport` | 디지털 여권 (표지 → 펼치기, 페이지 넘김, 도장 클릭 상세) |
| `#/stats` | 여행 기록 & 통계 (사이드바, 통계 카드, 최근 기록, 차트, 도장 컬렉션) |
| `#/collection` | COLLECT — 국가별 도장 컬렉션 (미발견 국가 잠금 표시) |
| `#/settings` | 설정 (직전 목적지 제외, 모션, 제외 도시 목록, 기록 초기화) |

## 주요 파일 구조

```
src/
  data/
    destinations.ts   # 큐레이션 목적지 28곳 (도시 콘텐츠)
    airports.ts       # 공항 레지스트리 (도시와 분리, 한 도시 ↔ 여러 공항)
    exclusions.ts     # 제외할 유명 도시 목록 — 여기만 수정하면 됨
    continents.ts     # 대륙 라벨·차트 색
    types.ts
  lib/
    destinations.ts   # 제외 필터, 공항 해석, 랜덤 선택(직전 목적지 제외)
    storage.ts        # 저장 모듈 (localStorage) — 백엔드 교체 시 이 파일만 바꾸면 됨
    geo.ts            # 위경도→3D 좌표, 구면 보간(slerp) 항적 곡선
    stats.ts          # 통계 계산 (국가 중복 집계 방지)
    wikiImage.ts      # Wikipedia 대표 사진 조회 + 캐시 + 실패 시 대체 이미지
  globe/
    Earth.tsx         # 지구 셰이더(낮/밤·도시 불빛·림 라이트), 대기층, 텍스처 실패 시 절차적 지구본
    GlobeScene.tsx    # 마커, 항적·잔광, 3D 비행기, 카메라 자동 회전/오토파일럿
  pages/              # Home, Destination, Passport, Stats, Collection, Settings
  components/         # TopNav, Stamp(SVG 입국 도장), PassportCover, 모달, 공통 UI
public/
  logo.png            # 제공된 로고(배경 투명화)
  textures/           # 지구 텍스처 (three-globe 패키지의 NASA Blue Marble / Black Marble)
```

## 구현된 기능

- 3D 지구본: 드래그 회전, 휠/핀치 확대·축소, 느린 자동 회전(조작 시 3초간 정지), 대기층·별·입자
- 랜덤 추첨: 제외 목록(도쿄·오사카·파리 등 14곳) 적용, 직전 목적지 제외 옵션, 도시 이름 셔플 연출
- 비행: ICN → 목적지 공항까지 구면 보간 곡선, 단계적 항적 생성, 접선 방향으로 회전하는 3D 비행기, 지나간 뒤 남는 잔광, 카메라 자동 추적, 건너뛰기
- 도착: 마커 발광, 기록 저장(여행 ID로 중복 방지), 약 4초 후 도시 정보로 자동 전환(머무르기 가능)
- 공항이 없는 도시(지로카스트라, 캔디, 발파라이소 등)는 연결 공항과 이동 정보 표시
- 디지털 여권: 표지 펼치기, 페이지 넘김, 국가별 색·모양·아이콘이 다른 SVG 도장, 도장 클릭 상세·메모 편집
- 통계: 실제 저장 데이터 기반(빈 상태는 0 + 첫 탐험 유도), 대륙별 도넛, 월별 막대, 도시 목록, 최근 도시
- 예외 처리: 초기 로딩, WebGL 실패 시 CSS 지구본 대체, 텍스처 실패 시 절차적 지구본, 이미지 실패 시 대체 그래픽, 잘못된 목적지 ID, 버튼 연타 방지, `prefers-reduced-motion` 대응(설정에서 직접 지정 가능)
- 반응형: 데스크톱(지구본 오른쪽 + 히어로 왼쪽), 모바일(지구본 상단 + 세로 정렬)

## 참고 / 미구현

- 사진은 Wikipedia REST API에서 런타임에 불러옵니다. 오프라인이거나 차단되면 대체 그래픽이 표시됩니다.
- 실시간 환율·비자 정보는 의도적으로 제공하지 않습니다(통화 이름·코드와 공식 출처 링크만 표시).
- 후보 중 루안다(앙골라)는 정보 정확도를 확보하기 어려워 초기 데이터에서 제외했습니다(`destinations.ts` 주석 참고).
- 로그인·백엔드 동기화는 미구현 — `lib/storage.ts`의 `TravelStore` 인터페이스만 구현하면 교체 가능합니다.
- 국기 이미지는 flagcdn.com에서 불러오며, 실패 시 국가 코드 배지로 대체됩니다.
